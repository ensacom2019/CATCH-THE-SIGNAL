# NAN // SIGNAL HUNT

48초 동안 화면에 나타나는 신호를 1부터 순서대로 클릭하는 미니 게임입니다.

## 게임 방법

- `START RUN`을 누릅니다.
- 화면에 나타난 신호를 1부터 순서대로 클릭합니다.
- 틀린 순서로 클릭하면 콤보가 초기화됩니다.
- 25초 이하가 되면 트랩 신호가 등장합니다.
- 제한 시간은 48초이며, 점수와 최고 콤보가 기록됩니다.

## 실행

정적 파일로 구성되어 있어 별도 빌드 없이 실행할 수 있습니다.

```bash
python -m http.server 4173
```

그 다음 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.
